Flipkart Trouser Sales Dashboard

This Power BI dashboard provides an interactive analysis of Flipkart trouser sales performance across different product categories. It highlights key business metrics such as total orders, net revenue, average order value, gross revenue, and return costs.

The dashboard uses interactive visualizations to compare product categories, identify top-performing products, and analyze return-related costs. It was developed using Power BI, Power Query, and DAX to transform raw sales data into meaningful business insights.

Key Features
📊 Product category-wise order analysis
💰 Gross and net revenue analysis
📦 Total orders and average order value
🔄 Return cost analysis
🎯 Interactive product category filters
📈 Business-focused KPI visualization
Tools Used

Power BI | DAX | Power Query | Data Cleaning | Data Analysis | Data Visualization | Business Intelligence
